# KantanBiz（SaaS 版）との対応

KantanBiz の利用者がデスクトップ版（DT）へ移るときの、機能の対応表です。
データの移行は「ファイル」→「KantanBiz から取り込む…」（`scripts/import-kantanbiz.php`）。

## DT にある機能（KantanBiz と同じように使える）

| 機能 | 実装 |
|---|---|
| 顧客・部署、協力会社・職能、サービス（初期費用・定期項目）、案件、請求・原価明細、契約（定期請求） | EX プラグイン本体 |
| 帳票（見積・受注・請求・発注書・見積依頼）、一括請求書、売上などのレポート、確定申告用 | EX プラグイン本体 |
| 案件ファイル、スタッフチャット、メール送信履歴 | EX プラグイン本体 |
| **タスクリスト（工程表つき）** | `site/mu-plugins/ktp-desktop/order-tasks.*` |
| **一括請求書の「請求済」の取り消し** | `invoice-undo.*` |
| **仕事リストの並び替え** | `work-list-sort.php` |
| **受注の CSV 書き出し** | `orders-csv.php` |
| **仕入・支払レポート、資金繰り予定、進捗レポート** | `reports-extra.php`、予定日の計算は `payment-schedule.php` |
| **顧客・協力会社へのニュースレター** | `newsletter.php`（設定した SMTP から送る） |
| **Web-FAX 送信**（eFax / jFax / MOVFAX） | `webfax.*`（書類を画面で PDF にして、SMTP でゲートウェイへ送る） |
| **KantanBiz からのデータ取り込み** | `scripts/import-kantanbiz.php` と `main.js` のメニュー |

## DT で作らないもの（理由つき）

DT は「インターネットに出ない・この Mac の中だけで動く」ことが前提です。次は、公開 URL・クラウド・複数人のアカウントが前提なので作りません。

| KantanBiz の機能 | 理由 |
|---|---|
| 複数オフィスの切替・招待・メンバー管理・メンバー間メッセージ | 1 つのアプリは 1 つの事業・1 人用 |
| ログイン・パスコード・ログイン履歴 | 自動ログイン。アカウントがない |
| Stripe の課金・フリープラン上限・ストレージ追加・紹介・アフィリエイト | SaaS 自体の課金。DT は買い切り |
| お客様向けの Stripe 決済、公開商品ページ、問い合わせ受信・ブロック | 公開 URL と受け口が要る |
| Webhook・HTTP API・トークン管理 | 外から呼び出される前提 |
| 他オフィスとの連携（パートナーシップ） | 共有のサーバーが要る |
| ヘルプ AI チャット、フィードバック送信 | インターネットが要る |
| 郵便番号の自動入力（zipcloud） | 郵便番号を外部へ送るため。日本郵便の API キーを設定すれば使える（本人が設定したときだけ通信） |
| 運営向け画面、活性化メール、無料ツール、llms.txt など | KantanBiz の運営・集客用 |

## 取り込み後に必要な操作

- メール（SMTP）のパスワードを設定画面で入れ直す（安全のため書き出されない）
- Web-FAX を使う場合は「Web-FAX 設定」（`?ktp_dt_page=webfax`）で契約中のサービスを選ぶ
- 担当者・チャットの投稿者は、DT 内のスタッフ（ログイン不要）として作られる
